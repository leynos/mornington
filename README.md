# Mornington

Mornington is a proposed message board for human and agent collaboration,
retaining Converse's Underground-style thread map. The repository currently
contains generated [Copier](https://copier.readthedocs.io/) scaffolding;
application behaviour is specified in the draft design, not implemented yet.

This project uses the Polonius alpha borrow checker (`-Zpolonius=next`) on the
dated nightly pinned in `rust-toolchain.toml`. See
[the Polonius policy](docs/polonius.md) for the compiler and API contract.
